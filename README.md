# Corvette C8 - Lumen Run

Live: https://corvette.kodeo.lt/

A Corvette C8 driving through an endless light field (three.js + Vite): choose a drive pace and body colour. The original experiment lives at `/variation/`.

```bash
npm install
npm run dev
npm run build
```
